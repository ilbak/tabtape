# 🎵 TabTape

**TabTape** is a minimal, local-first web app for playing audio files directly from a folder on your computer — no uploads, no server, no dependencies. Just open the HTML file in your browser, pick a folder, and listen. In a a single self-contained HTML file.

## Features

- 📁 **Folder-based playback** — choose a local folder and TabTape loads all supported audio files automatically.
- 🔀 **Shuffle & sequential playback** — toggle shuffle to play tracks at random, or play them in order.
- 📋 **Playlist with live search** — filter tracks by name; the filtered list becomes a temporary playlist for "next" and shuffle.
- ↕️ **Custom sorting** — order tracks by name A–Z, Z–A, or keep the original folder order.
- ⏯️ **Full playback controls** — play/pause, next, and a progress bar with seek and elapsed / remaining time.
- 🧹 **Clear** — stop playback and empty the playlist (files on disk are untouched).
- 💾 **Session persistence** — remembers the last folder, the last played track, the shuffle state, and the sort order. Reopens the previous folder automatically on reload.
- 🌑 **Dark, modern UI** — clean minimal design that stays out of the way.

## Usage

1. Download or clone the repository.
2. Open `tabtape.html` in your browser (double-click works — no server required).
3. Click **Choose folder** and select a directory containing audio files.
4. Enjoy. 🎧
